# Política de seguridad — F7777techMods

## Alcance

F7777techMods es una aplicación de escritorio local. No envía telemetría por defecto y no requiere cuenta en línea para funcionar.

## Informar un problema

Si crees haber encontrado una vulnerabilidad:

1. **No** abras un issue público con exploits o datos privados.
2. Contacta a Four Seven Tech vía https://fourseven.es/ (canal apropiado del sitio) o un aviso privado al titular del repo https://github.com/raulito07/F7777techMods.
3. No abras un issue público con exploits; si usas issues, describe el problema de forma genérica **sin** payloads ni rutas personales.

## Buenas prácticas al usar el software

- No ejecutes Apply sobre juegos reales sin copia de seguridad.
- No desactives protecciones de Windows para «hacer funcionar» el portable sin firma.
- No compartas tu carpeta `%LOCALAPPDATA%\FourSevenTech\F7777techMods\` ni logs con rutas absolutas en issues públicos.

## Dependencias

Revisa [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) y actualiza dependencias en desarrollo con `pip` cuando haya avisos de seguridad relevantes.
